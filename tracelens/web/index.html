What the comparison can tell us

The event-frequency baseline tests how much can be detected without sequence context.

The shuffled-training LSTM removes order within training windows while preserving their event counts. Seeds expose training variability.

A separate test-time permutation probe changes event order while preserving counts. It measures sensitivity to a perturbation, not performance on a new real system.

A larger model is not automatically better. Compare precision–recall behavior and false alarms before selecting an architecture.
